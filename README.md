# PROTECT-MD V1

Interface locale: http://127.0.0.1:3005/

Installation Termux:
```bash
cd ~
unzip -o PROTECT-MD-V1-3005.zip -d PROTECT-MD-V1
cd PROTECT-MD-V1
npm install
npm start
```

Commande WhatsApp unique:
.status

Protection automatique:
- anti-spam
- suppression des messages suspects
- antivirus heuristique
- ANTI-ABUSE
- blocage des expéditeurs directs après détection de flood/répétition
- tableau de contrôle en plusieurs étapes
- indicateur interne de fiabilité

Limites:
Le bot ne peut pas fournir une certification Meta Verified ni garantir une protection absolue. L'antivirus est une analyse heuristique de messages et ne remplace pas un antivirus Android.
